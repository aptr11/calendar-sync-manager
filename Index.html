How to Stop Automatic Sync at Any Time
Every time a sync runs, duplicates are cleaned up and you receive an email report listing all changes and a link back to this page. To stop automatic syncing:
  1. Open this Web App (using your bookmark or the link inside any sync email).
  2. Click the red Stop Auto-Sync button above (visible whenever a recurring schedule is active), or set Automatic Recurring Sync to Manual Only and click Save & Sync Now.
