How to Stop Automatic Sync at Any Time

Every time a sync runs, duplicates are cleaned up and you receive an email report listing all changes and a link back to this page. To stop automatic syncing:

  1. Open this Web App (using your bookmark or the link inside any sync email).
  2. Click the red Stop Auto-Sync button above (visible whenever a recurring schedule is active), or set Automatic Recurring Sync to Manual Only and click Save & Sync Now.
Multi-User & Multiple Accounts Setup
Note on multi-account switching: Due to technical difficulties with Google Apps Script multi-session handling (which causes Google Drive "unable to open file" errors and session collisions), in-app account switching is not supported.

To use this application with multiple Google accounts (e.g. personal and work) or to set up sync for a different user, please use one of the following methods:

  • Different Chrome Profile (Recommended): Create or switch to a dedicated Google Chrome profile for each Google account. This provides complete session isolation and prevents all cookie collision issues.
  • Other Browser: Open the Web App URL in another browser (e.g., Firefox, Safari, Microsoft Edge, Brave) logged into the other Google account.
  • Incognito / Private Window: Open an Incognito window, sign into the target Google account, and access the Web App.
